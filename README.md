# Heart Disease Risk Predictor

A Machine Learning web application that predicts heart disease risk using Random Forest Classifier.

## Features
- Predicts heart disease risk
- Built with Streamlit
- Machine Learning using Scikit-learn

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
